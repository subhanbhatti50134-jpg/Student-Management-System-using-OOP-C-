# License decision — Student Management System (C++ OOP)

This repository is a beginner C++ learning project. It does **not** yet carry
an open-source license. Until a license is added, all rights are reserved by
default.

## Recommended options

### Option A — MIT License (recommended for student projects)
- Lets others learn from, fork, and reuse the code.
- Short, clear, with a warranty disclaimer.
- Most common choice for open-source student/learning projects.

### Option B — Apache-2.0
- Like MIT with an explicit contributor patent grant.
- Good if you want permissive reuse with added patent clarity.

### Option C — No license / "All Rights Reserved"
- Keep full control; others cannot legally reuse or distribute the code.

## Recommendation

For a C++ learning project whose main purpose is to demonstrate understanding
of OOP and file handling, **MIT** is a good fit: it signals professionalism
and invites other learners to read and fork the code.

## How to adopt (if choosing MIT)

1. Add a `LICENSE` file at the repository root with the MIT license text.
2. Add copyright: `Copyright (c) 2026 Muhammad Subhan`.
3. Keep this `LICENSE_DECISION.md` as the decision record.
